# ⚡ ПОТУЖНО SHOP (Potuzhno E-Commerce Platform)

Повноцінний сучасний вебзастосунок інтернет-магазину на базі **Django** та **DRF**.

## 🛠 Технологічний стек
* **Backend:** Python 3.14, Django, DRF
* **Database:** PostgreSQL / SQLite
* **Testing:** 100% покриття (100 юніт-тестів)

## 🚀 Запуск тестів
```bash
python manage.py test
